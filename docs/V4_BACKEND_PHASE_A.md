## Raw format

`raw-structural-model-v4.json` is intentionally **not** schema v4.

It contains all-method Joern facts needed by the future source-semantic normalizer:

- internal types and inheritance;
- all relevant internal source methods;
- raw parameters and return types;
- AST nodes with parent/child structure;
- source code / offsets where the frontend provides them;
- calls including semantic operators;
- call arguments/types and Joern possible callees;
- typed control body relations;
- Return / JumpTarget nodes through the AST;
- Python raise through operator calls.

Production/test filtering is intentionally deferred to normalization.

## Scratch-output policy

`results/v4-fixtures/` is generated by the Phase A fixture runner and is intentionally
ignored by Git. It contains CPGs and raw structural JSON used to validate the exporter.

Do not commit these generated fixture outputs unless a later milestone intentionally
promotes selected normalized models to golden regression fixtures.
